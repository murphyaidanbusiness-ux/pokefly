# roms

Drop your own Pokemon Red ROM in this folder: one `.gb` file, about 1 MB.
Any name works. If there is more than one `.gb` here, the one called
`pokemon_red.gb` wins; otherwise `run.py` lists them and asks you to keep one.

Nothing in this project downloads a ROM, and everything in this folder except
this file is gitignored, so your ROM never gets committed.
